# Food Shop – Overview

## 1. Project Summary
An **online food ordering website** that helps users order meals quickly and conveniently.  
Technologies: **ASP.NET Core**, **Entity Framework**, **SQL Server**.


## 2. Roles & Permissions

| Role | Permissions | 
|------|--------------|
| **User** | Create orders, view order history, chat with shop staff |
| **Sale** | Manage orders for their shop, chat with users | 
| **Admin** | Manage all users, shops, foods, and view any chat |
